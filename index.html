Performance & observability

Building an endpoint is the first half. The second half is knowing how it behaves when 200 users hit it at once — and being able to point at the reason. Here is how the Society Management System was validated.

01

Load

k6 drives the API at 200 concurrent virtual users across 17,922 HTTP requests, exercising authenticated endpoints rather than a single health check.

02

Observe

Prometheus scrapes application metrics; Grafana dashboards make request rate, latency and error behaviour visible while the test runs.

03

Fix

Findings turn into concrete changes: compound MongoDB indexes for integrity and lookup cost, N+1 query optimization on bulk endpoints, Redis caching on hot reads.

04

Scale

Kubernetes horizontal pod autoscaling handles load growth, with configuration and credentials externalized through ConfigMaps and Secrets.
